📊 **Finance Tracker (Python)**

Личный финансовый трекер на Python для учёта расходов и доходов, анализа бюджета и визуализации статистики.
Проект создан как учебный, но имеет полноценную архитектуру и может использоваться в реальной жизни.

🚀 **Возможности**

- добавление расходов и доходов
- категории (еда, жильё, транспорт, развлечения и др.)
- просмотр транзакций по дате и категории
- статистика за день / месяц / год
- графики расходов (`matplotlib`)
- хранение данных в SQLite
- экспорт отчётов (в будущем)

🧱 **Архитектура проекта**

```
finance_tracker/
│── main.py                # Точка входа
│── database.py            # Подключение и создание таблиц SQLite
│── models.py              # Логика транзакций
│── stats.py               # Аналитика и статистика
│── ui_console.py          # Консольный интерфейс
│── utils.py               # Вспомогательные функции
│── requirements.txt       # Зависимости проекта
│── data/
│     └── finance.db       # База данных (игнорируется Git)
│── reports/
│     └── charts/          # Графики расходов
│── .gitignore             # Игнорируемые файлы
```
📦 **Установка и запуск**

1) Клонировать репозиторий
```
git clone https://github.com/your-username/finance-tracker-python.git
cd finance-tracker-python
```
2) Создать виртуальное окружение
```
python -m venv .venv
```
3) Активировать окружение

Windows:
```
.venv\Scripts\activate
```
macOS / Linux:
```
source .venv/bin/activate
```
4) Установить зависимости
```
pip install -r requirements.txt
```
5) Создать базу данных
```
python database.py
```
6) Запустить приложение
```
python main.py
```
🗄️ **Технологии**

- Python 3.12 — основная версия
